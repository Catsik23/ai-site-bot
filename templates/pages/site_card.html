🔑 Ключи Яндекса

Для работы бота нужен ваш API-ключ Yandex Cloud

📖 Как получить API-ключ Яндекса

Всего 2 шага по 2 минуты

Шаг 1: Сервисный аккаунт
  1. Откройте console.cloud.yandex.ru
  2. Слева выберите Сервисные аккаунты
  3. Нажмите Создать сервисный аккаунт
  4. Имя: любое (например, neuro-bot)
  5. Нажмите Роли в каталоге → выберите ai.languageModels.user
  6. Нажмите Создать
Шаг 2: API-ключ
  1. Нажмите на созданный сервисный аккаунт
  2. Перейдите на вкладку API-ключи
  3. Нажмите Создать API-ключ → Создать
  4. Скопируйте значение (начинается с AQVN...)
  5. Вставьте в поле Yandex API Key в настройках
